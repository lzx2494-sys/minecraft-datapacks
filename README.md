## Packs

Crafting recipes for all 83 spawn eggs: **Egg + mob-themed material = Spawn Egg**.

- Blaze Spawn Egg = Egg + Blaze Rod

## Installation

1. Download the .zip
2. Drop it into your world's `datapacks` folder
3. Run `/reload` or rejoin the world

Requires Minecraft Java Edition 1.21.2+. Multiplayer friendly.
