# Minecraft Datapacks by BestMinecraftID

Free, survival-friendly Minecraft datapacks. No mods required.

ID data maintained by [bestminecraftid.com](https://bestminecraftid.com) — a full Minecraft ID catalog (items, blocks, enchantments, effects, entities, biomes) with one-click command generators (/give, /summon, /fill, /tellraw).

## Packs

### All Spawn Eggs Craftable

Crafting recipes for all 83 spawn eggs: **Egg + mob-themed material = Spawn Egg**.

Examples:
- Creeper Spawn Egg = Egg + Gunpowder
- Blaze Spawn Egg = Egg + Blaze Rod
- Enderman Spawn Egg = Egg + Ender Pearl
- Warden Spawn Egg = Egg + Echo Shard + Sculk Catalyst

Download: [AllSpawnEggsCraftable.zip](all-spawn-eggs-craftable/AllSpawnEggsCraftable.zip)

Full spawn egg ID list: https://bestminecraftid.com/types/spawn-eggs/
Need a /give command instead? Generate one in a click: https://bestminecraftid.com/tools/give-command-generator/

## Installation

1. Download the .zip
2. Drop it into your world's `datapacks` folder
3. Run `/reload` or rejoin the world

Requires Minecraft Java Edition 1.21.2+. Multiplayer friendly.
